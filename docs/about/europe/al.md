## Road traffic

### Road defaults

Albania publishes no open per-segment AADT, so roads fall back to the global class defaults scaled by Albania's traffic factor **≈ 1.284** (vehicles-per-km). Only the major classes (motorway, trunk, primary, and their on/off-ramps) are scaled; local roads and the vehicle mix use the global default — the engine applies no per-city tiers or country-specific splits.

| OSM class | Default AADT |
|---|---:|
| Motorway | 30,000 × 1.284 ≈ 38,520 |
| Trunk | 15,000 × 1.284 ≈ 19,260 |
| Primary | 9,000 × 1.284 ≈ 11,556 |
| Secondary / tertiary / residential | 3,000 / 800 / 500 (world default) |
| Service / track / unclassified | 250 / 5 / 1,340 (world default) |

## Industrial

### GEM — 66 plants, 20 operating, ~1.99 GW — **100% RENEWABLE**

Hydro 7 + solar 13. **ZERO fossil fuel** in GEM operating fleet — **one of Europe's only countries with ~100% renewable generation** (alongside Norway and Iceland).

**Drin River cascade**: **Koman 600 + Fierza 500 + Vau i Dejës 250 = 1,350 MW** — Albania's hydro backbone. **Devoll cascade**: Moglicë 197 + Banjë 72 (Statkraft/Shell 2020). **Karavasta Solar 140 MW** (largest, Adriatic coast).

### Key sites not NACE classified
- Bankers/Geo-Jade Patos-Marinza (Europe's largest onshore oil field by area — Chinese since 2016)
- ARMO refinery (Ballsh/Fier — old, small)
- Kurum International steel (Elbasan)
- Bulqizë chrome (world's 3rd largest chrome reserves)
- Antea Cement (Holcim-Titan, Krujë)
